This project is my PhD project. Using EEG, this project examines how speakers use auditory information to monitor their vocal pitch. This project is supervised by Dr. Defne Abur, Dr. Frank Tsiwah, and Prof. dr. Martijn Wieling (funded by Dutch Ministry of Education, Culture, and Science Starter Grant awarded to Dr. Defne Abur & Dr. Frank Tsiwah).
